# WPCP Transit Tracker
### By John Charles Falciglia (Juan Carlos Falciglia)
---------------------------------
Hi, welcome to the WPCP transit tracker/information system. This is a student developed information system, and also a student-developed README.
This is for all y’all future Payton students, and is a guide on the information system, the software, what it runs on, how to modify it, rules and reg, etc.
## Purpose:
Develop a neater, more informative, more readable, and more space efficient display for the screen in the center of the atrium
## The Software
This is a website, that pulls from a couple different APIs and displays the information
APIs: CTA Train Tracker, CTA Bus Tracker, CTA Customer Alerts, and a weather API.
It uses written CSS, no externals like boot strap, partially because I don't need animations and all that jazz.
It also uses in line JS, to fetch data, and manipulate it to be displayed.
## The Hardware
It runs on the Security TV in the lobby and it runs on a system called Airtame 2, which can display slides, YouTube, websites, and more. So, if you want to switch it up later on, feel free to.
## How to modify
Edit the CSS file for decorative things, the HTML file for positioning, and the JS. Be careful when modifying, however, as there are specific regulations that must be followed due to copyright laws and stuff like that.
## Rules and Regulations
This is really IMPORTANT, so I suggest understanding this if you want to actually change stuff and not get in trouble. The CTA has certain rules and regulations on color. When using the API, they want you to use the Official CTA Transit COLORS, so like red line red and brown line brown. These colors are already the ones used, and if you think they look ugly, that's a you problem, and can't and won't be fixed. Arguably more important: you can’t use any past, present or future CTA LOGO  as doing so could lead to legal issues. Next, the images alongside both the Bus and Train sections are the official Train and Bus Tracker icons, respectively, which you CAN USE. HOWEVER, remember that the full icon must be visible and not obscured. I would recommend keeping it as is; you can also remove it, but either way, make sure that you follow all proper practices. Also, this was a quick overview of rules and regs; look at this: https://www.transitchicago.com/developers/terms/ and https://www.transitchicago.com/developers/branding/
before proceeding
